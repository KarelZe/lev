# lev

`lev` is an extremely fast Python library for comparing strings, written in Rust. 🦀 It computes the [Levenshtein distance](https://en.wikipedia.org/wiki/Levenshtein_distance) and a similarity ratio based on the [longest common subsequence](https://en.wikipedia.org/wiki/Longest_common_subsequence).

## Installation

```bash
uv add lev-rs
```

or with pip:

```bash
pip install lev-rs
```

Wheels are available for Python 3.10 through 3.15, including free-threaded Python (3.13t+), on Linux, macOS, and Windows.

## Usage

```python
import lev

lev.distance("kitten", "sitting")  # 3
lev.distance("résumé", "resume")  # 2
lev.distance("日本語", "日本")  # 1

lev.ratio("kitten", "sitting")  # 0.615...
lev.ratio("abc", "xyz")  # 0.0
lev.ratio("", "")  # 1.0
```

`lev.ratio` returns the same values as `rapidfuzz.fuzz.ratio(s1, s2) / 100` and `Levenshtein.ratio`.

See the [API Reference](https://karelze.github.io/lev/api/) for details.

### Rust

`lev` is also published as the [`lev-rs`](https://crates.io/crates/lev-rs) crate:

```bash
cargo add lev-rs
```

```rust
assert_eq!(lev::distance("kitten", "sitting"), 3);
assert_eq!(lev::ratio("abc", "xyz"), 0.0);
```

The crate requires Rust 1.91 or newer. See [docs.rs](https://docs.rs/lev-rs) for details.

### Benchmark Scripts

Reproduce benchmarks locally using the provided scripts:

```bash
# Compare against other libraries:
uv run scripts/benchmark.py

# Benchmark scaling across string lengths:
uv run scripts/benchmark_by_length.py

# Benchmark speedup across released versions:
uv run scripts/benchmark_by_version.py

# Compare against other Rust crates:
(cd benches/compare && cargo bench) && uv run scripts/benchmark_rust.py
```
